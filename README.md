# HostelHub – Hostel Management System

HostelHub is a web-based hostel management system developed to manage student records, hostel rooms, room allocations, and fee records through a centralized interface.

## Features
- Dashboard with hostel summary statistics
- Student record management
- Room and capacity management
- Student-room allocation management
- Fee record tracking, including paid and pending fees
- Backend API integration with a MySQL database
- Input validation and error handling

## Technologies Used
- **Frontend:** React.js, Vite, JavaScript, CSS
- **Backend:** Java, Spring Boot, Maven
- **Database:** MySQL
- **API:** REST

## Project Structure
- `backend/` – Spring Boot backend application
- `frontend/` – React frontend application

## Local Setup
1. Install Java, Maven, Node.js, and MySQL.
2. Configure your local database credentials in the backend environment.
3. Start the Spring Boot backend on port `8080`.
4. Install frontend dependencies using `npm install` inside `frontend/`.
5. Start the frontend using `npm run dev`.
6. Open `http://localhost:5173/` in your browser.

## Note
This project was tested locally. Refer to the project configuration and test results for the current verification status. Do not commit database passwords or other secrets.
